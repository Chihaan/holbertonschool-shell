# Holberton School - Shell

Ce repository regroupe les projets réalisés autour du shell UNIX/Linux (bash) : navigation dans le système de fichiers, permissions, variables d'environnement, redirections et filtres.

## Sous-dossiers

| Dossier | Description |
|---|---|
| `basics/` | Commandes shell de base : navigation, copie, suppression, liens symboliques, `tree` |
| `permissions/` | Gestion des permissions et propriétaires de fichiers (`chmod`, `chown`, `chgrp`) |
| `init_files_variables_and_expansions/` | Fichiers d'initialisation, variables d'environnement, expansions arithmétiques |
| `io_redirections_and_filters/` | Redirections d'entrée/sortie et filtres texte (`grep`, `sed`, `sort`, etc.) |
