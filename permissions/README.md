# Shell, permissions

## Description
Scripts autour de la gestion des permissions UNIX : identité des utilisateurs, groupes, droits d'accès (`chmod`) et propriétaires (`chown`, `chgrp`).

## Fichiers

| Fichier | Description |
|---|---|
| `0-iam_betty` | Change l'utilisateur courant en `betty` |
| `1-who_am_i` | Affiche l'utilisateur effectif courant |
| `2-groups` | Affiche les groupes de l'utilisateur courant |
| `3-new_owner` | Change le propriétaire d'un fichier |
| `4-empty` | Crée un fichier vide nommé `hello` |
| `5-execute` | Ajoute le droit d'exécution au propriétaire d'un fichier |
| `6-multiple_permissions` | Modifie plusieurs permissions en une seule commande |
| `7-everybody` | Donne tous les droits à tout le monde sur un fichier |
| `8-James_Bond` | Applique des permissions `007` à un fichier |
| `9-John_Doe` | Applique des permissions `733` à un fichier |
| `10-mirror_permissions` | Copie les permissions d'un fichier vers un autre |
| `11-directories_permissions` | Ajoute le droit d'exécution à tous les répertoires |
| `12-directory_permissions` | Crée un répertoire avec des permissions spécifiques |
| `13-change_group` | Change le groupe propriétaire d'un fichier |
| `14-change_owner_and_group` | Change simultanément propriétaire et groupe |
| `15-symbolic_link_permissions` | Modifie les permissions de la cible d'un lien symbolique |
| `16-if_only` | Change le propriétaire d'un lien symbolique sans suivre le lien |
