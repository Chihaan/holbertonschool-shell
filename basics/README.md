# Shell, basics

## Description
Premiers scripts shell : navigation dans le système de fichiers, manipulation de fichiers et dossiers, liens symboliques et affichage d'arborescence.

## Fichiers

| Fichier | Description |
|---|---|
| `0-current_working_directory` | Affiche le répertoire de travail courant |
| `1-listit` | Liste le contenu du répertoire courant |
| `2-bring_me_home` | Change de répertoire vers le dossier personnel |
| `3-listfiles` | Liste les fichiers avec des permissions lisibles pour un humain |
| `4-listmorefiles` | Liste tous les fichiers, y compris cachés, sauf `.` et `..` |
| `5-listfilesdigitonly` | Liste les fichiers en affichant uniquement l'UID et le GID numériques |
| `6-firstdirectory` | Crée un répertoire nommé `my_first_directory` |
| `7-movethatfile` | Déplace un fichier vers un autre dossier |
| `8-firstdelete` | Supprime un fichier |
| `9-firstdirdeletion` | Supprime un répertoire vide |
| `10-back` | Revient au répertoire précédent |
| `11-lists` | Crée un fichier nommé `#11-lists#` |
| `12-file_type` | Affiche le type de tous les fichiers d'un répertoire |
| `13-symbolic_link` | Crée un lien symbolique |
| `14-copy_html` | Copie tous les fichiers `.html` vers un dossier |
| `15-lets_move` | Déplace tous les fichiers commençant par une majuscule |
| `16-clean_emacs` | Supprime les fichiers de sauvegarde Emacs |
| `17-tree` | Compte le nombre de dossiers dans une arborescence |
