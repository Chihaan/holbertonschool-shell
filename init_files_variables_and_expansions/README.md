# Shell, init files, variables and expansions

## Description
Exploration des fichiers d'initialisation du shell (`.bashrc`, alias), des variables d'environnement/locales et des différents types d'expansions (arithmétique, commande, tilde).

## Fichiers

| Fichier | Description |
|---|---|
| `0-alias` | Crée un alias `ls` qui exécute `rm *` (piège pédagogique) |
| `1-hello_you` | Crée un alias affichant `hello` suivi du nom d'utilisateur |
| `2-path` | Ajoute un répertoire au `PATH` |
| `3-paths` | Compte le nombre de répertoires dans le `PATH` |
| `4-global_variables` | Liste toutes les variables d'environnement |
| `5-local_variables` | Liste toutes les variables locales, environnement et fonctions |
| `6-create_local_variable` | Crée une variable locale |
| `7-create_global_variable` | Crée une variable d'environnement |
| `8-true_knowledge` | Additionne 128 à la variable `TRUEKNOWLEDGE` |
| `9-divide_and_rule` | Divise `POWER` par `DIVIDE` |
| `10-love_exponent_breath` | Calcule `BREATH` élevé à la puissance `LOVE` |
| `11-binary_to_decimal` | Convertit un nombre binaire en décimal |
| `12-combinations` | Affiche toutes les combinaisons de deux caractères, sauf `oo` |
| `13-print_float` | Affiche un nombre flottant avec 2 décimales |
| `14-decimal_to_hexadecimal` | Convertit un nombre décimal en hexadécimal |
| `15-rot13` | Encode le texte reçu en ROT13 |
| `16-odd` | Affiche uniquement les nombres impairs d'un fichier |
| `17-water_and_stir` | Complète une fonction en ajoutant `sugar` et `mint` |
