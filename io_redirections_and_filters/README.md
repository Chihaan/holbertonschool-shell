# Shell, I/O Redirections and filters

## Description
Scripts utilisant les redirections d'entrée/sortie (`>`, `>>`, `<`, `|`) et les filtres texte classiques (`grep`, `sed`, `sort`, `tr`, `wc`, `find`) pour manipuler des fichiers.

## Fichiers

| Fichier | Description |
|---|---|
| `0-hello_world` | Envoie "Hello, World" sur la sortie d'erreur standard |
| `1-confused_smiley` | Corrige l'orientation d'un smiley dans un fichier |
| `2-hellofile` | Envoie le contenu de `/etc/passwd` dans un fichier `iamfile` |
| `3-twofiles` | Concatène deux fichiers dans un troisième |
| `4-lastlines` | Affiche les 10 dernières lignes de `/etc/passwd` |
| `5-firstlines` | Affiche les 10 premières lignes d'un fichier |
| `6-third_line` | Affiche uniquement la 3e ligne d'un fichier |
| `7-file` | Affiche le type de tous les fichiers d'un dossier |
| `8-cwd_state` | Sauvegarde l'état du répertoire courant dans un fichier caché |
| `9-duplicate_last_line` | Duplique la dernière ligne d'un fichier |
| `10-no_more_js` | Supprime tous les fichiers `.js` d'un répertoire |
| `11-directories` | Compte le nombre de répertoires (hors cachés) dans le dossier courant |
| `12-newest_files` | Liste les 10 fichiers les plus récemment modifiés |
| `13-unique` | Affiche les lignes uniques d'un fichier |
| `14-findthatword` | Compte le nombre d'occurrences d'un mot dans un fichier |
| `15-countthatword` | Compte le nombre total d'un mot, insensible à la casse |
| `16-whatsnext` | Affiche les lignes suivant une occurrence d'un mot |
| `17-hidethisword` | Remplace un mot par des astérisques |
| `18-letteronly` | Affiche les lignes ne contenant que des lettres |
| `19-AZ` | Remplace les caractères selon un motif de substitution |
| `20-hiago` | Remplace "Iago" par "hiago" dans un fichier |
| `21-reverse` | Affiche un fichier dans l'ordre inverse des lignes |
| `22-users_and_homes` | Affiche les utilisateurs et leurs répertoires personnels |
| `23-empty_casks` | Supprime les lignes vides d'un fichier |
| `24-gifs` | Liste tous les fichiers `.gif` d'un dossier |
| `25-acrostic` | Extrait la première lettre de chaque ligne d'un fichier |
| `26-the_biggest_fan` | Répète une phrase un nombre donné de fois |
